Breaking changes:

- The key used to override LSP-wren-lsp settings in project settings has changed from `wren-lsp` to `LSP-wren-lsp`.
  If you use project-specific overrides for LSP-wren-lsp, you have to rename the key for them to apply:

  Before:

  ```jsonc
  {
      "settings": {
          "LSP": {
              "wren-lsp": {
                  // ...
              }
          }
      }
  }
  ```

  After:

  ```jsonc
  {
      "settings": {
          "LSP": {
              "LSP-wren-lsp": {
                  // ...
              }
          }
      }
  }
  ```
